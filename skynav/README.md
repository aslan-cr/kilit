# SkyNav (Flutter)

Beyaz/buzlu cam tasarımlı hava durumu, 3D harita, uçak radarı, yol tarifi ve gökyüzü uygulaması. **Bu depoda 1. yarı** hazır: giriş/ekosistem, politika-izin akışı, davet/indirim/ödül/satın alma altyapısı, dinamik ikon, canlı gökyüzü arka planı, hava durumu modu ve yaşam laboratuvarı.

- Derleme: `cd skynav && flutter pub get && flutter build apk` (Flutter 3.35+). Firebase için `FIREBASE_KURULUM.md`.
- Gerçek ses dosyaları: `assets/audio/README.md`.
- Bu klasörde `build.gradle.kts` olmadığı için kökteki Gradle çok modüllü yapıya dahil edilmez.
