# Gerçek doğa kayıtları (CC0)

Uyku mikseri YALNIZCA gerçek kayıt kullanır; kodla üretilmiş (sentetik) ses yoktur.
Aşağıdaki adlarla telifsiz (CC0) .ogg dosyalarını bu klasöre koy:

- rain_loop.ogg, wind_loop.ogg, thunder_distant.ogg, forest_night.ogg

Kaynak önerisi: freesound.org (lisans filtresi "Creative Commons 0"), pixabay.com/sound-effects.
Dosya yoksa mikser ilgili kanalda "Ses dosyası pakette yok" der, uygulama çökmez.
Buton tıkları ve uyarılar telefonun kendi sistem sesleri/titreşimidir.
